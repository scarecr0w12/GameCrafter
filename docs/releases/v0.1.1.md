# GameCrafter 0.1.1 testing prerelease

**Date:** 2026-10-01

This testing prerelease brings the latest GameCrafter platform into versioned Windows/Linux packages. It is intended for local evaluation, with the normal user profile kept separate by the Windows test launcher.

## Included changes

- Dark violet/neon green Control Room theme and responsive workspace views.
- Thirty bundled game-development skills with detailed domain references, Project enablement, role-aware activation and bounded reference reads.
- Project-scoped chat, supervised agent/Swarm workflows, model routing, discussion records and knowledge retrieval.
- Settings import/export, Audit & History and asset/provider contract repairs.
- Project clone/restore identity corrections, process cleanup/timeouts, IPC error containment and update verification repairs.
- Unity/Unreal live acceptance tooling and regression coverage for editor identity, screenshots and external JSON Schema dialects.
- Detailed user, developer, architecture, integration, operations, RPC and settings documentation.
- Synchronized workspace versions, tag/version guards, versioned local output and verification of shipped skill content and notices.

## Test this version

Use the Windows NSIS installer attached to the GitHub prerelease, or the staged local `Windows-Release/0.1.1/Launch-GameCrafter-Test.cmd`. The latter launches the adjacent unpacked application with a dedicated profile/configuration. See the [release guide](../RELEASE_GUIDE.md) for reproducible commands and artifact locations.

Verify the downloaded assets against `SHA256SUMS.txt`. Application/service versions are 0.1.1; package filenames, metadata and tag use the same version. The release manifest records the exact source commit.

## Known limitations

This is an unsigned testing prerelease unless the supplied metadata/signatures or executable explicitly establish signing. Signing keys and a Windows certificate are not provisioned by the repository. Checksum verification is separate from publisher authentication.

Installer install/uninstall and upgrade/rollback acceptance remain open. Live model/generation providers, broader engine/OS targets, physical Windows input/accessibility, production-game validation, remote backup recovery and Windows plugin isolation also retain the boundaries in [implementation status](../STATUS.md). The existing in-app stable update channel does not offer prereleases.
