# PlayWeld 0.1.4: public rebrand and visual identity

**Last updated:** 2026-10-02

## Contents

The desktop product is now presented as **PlayWeld**. The rebrand covers app and installer titles, menus, Settings and theme labels, assistant identity, service and update messages, new Project instruction templates, automated Git author display names, current documentation, and bundled skill prose. New Windows installer artifacts use `PlayWeld-0.1.4-x64.exe`.

The authored visual family includes an angular W and welding spark, editable SVG logos and wordmarks, transparent PNG variants, multi-size app icons, a Windows ICO, repository/social banners, and two generated marketing illustrations. See the [asset handoff](../../assets/brand/README.md). The app home header and favicon use the canonical mark, and the desktop package includes the new icons.

## Compatibility

All nine first-party workspaces and their lockfile entries use version 0.1.4. Existing application IDs, executable names, npm scope, profile paths, Project records, environment variables, plugin manifests, and repository/release-feed URLs retain their prior identity. See [branding compatibility](../BRANDING.md). Previously staged releases and historical evidence are preserved. Existing Projects are not rewritten solely to change the name in their instruction files; newly created/cloned instruction templates use PlayWeld.

## Scope

No website code, DNS, hosting, or domain services are included. Website implementation belongs to the user's separate project; the portable artwork can be reused there. The logo direction is an authored default rather than a separately user-confirmed creative decision. Community trademark/fork-branding policy remains open.
