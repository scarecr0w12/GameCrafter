# GameCrafter 0.1.2 testing prerelease

**Date:** 2026-10-01

This patch repairs Control Room forms, model selection, chat request ownership and compact desktop layouts. It preserves the testing channel and the existing local platform-service storage boundary.

## Included changes

- Closed Control Room views get fresh widgets when reopened, preventing disposed widgets from producing blank tabs.
- Field-backed controlled inputs update immediately. Settings text, number and list fields save on blur; model name and tag editors reflect the saved canonical values.
- Model discovery previews the provider catalog without persisting it. Each account has a model picker with Add selected and Add all actions.
- Chat captures its originating Project, conversation, history, model, mode and editor context before asynchronous work. Navigation cannot redirect a response or its streamed text to another conversation. Late errors remain with the origin, and stale history reads cannot replace the current transcript.
- Chat retains a 320-pixel minimum dock width and adapts to its container width. Compact docks use a conversation dropdown. Settings controls wrap and remain reachable through vertical scrolling, and Home navigation buttons preserve words. The desktop window has an 800-by-600 minimum size.

## Verification

- A clean install and the full build, typecheck, lint and test run passed all 33 tasks at version 0.1.2. The platform-service suite had 330 passing tests and 11 configured skips; the Control Room extension had 27 passing tests, including eight chat ownership regressions.
- The rebuilt Electron desktop was exercised at actual renderer sizes of 800 by 600 and 1440 by 1000 with a real platform service and an isolated fake HTTP/streaming provider. Checks included keyboard composition, the physical Send button, project and conversation navigation during responses, persisted answer ownership, Settings search/select/reset, and control bounds beside the Chat dock. No renderer errors were recorded.
- Settings/model browser regressions verified repeated tab reopening, form input persistence, preview without writes, selected/add-all actions and saved model name/tag values.
- Both application builds, formatting and diff checks passed.

The repeatable interaction checks are [chat-layout-ui-smoke.cjs](../../scripts/chat-layout-ui-smoke.cjs) and [settings-models-ui-smoke.cjs](../../scripts/settings-models-ui-smoke.cjs). The [release workflow](../../.github/workflows/release.yml) performs packaging checks on the tagged source; its run and attached artifacts are separate release evidence.

## Installation and limits

Obtain the versioned Windows NSIS installer or Linux AppImage/DEB from this testing prerelease. Verify the files against `SHA256SUMS.txt`; `gamecrafter-release.json` records their hashes, the version and exact source commit. See the [release guide](../RELEASE_GUIDE.md).

The existing stable in-app update channel excludes testing prereleases. Signing status is determined by the attached metadata/signatures and executable; checksums alone are not publisher authentication. Paid-provider integration, installer install/uninstall, upgrade/rollback acceptance and the broader boundaries in [implementation status](../STATUS.md) remain open.
